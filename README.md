## StudentAttendanceApp

A C# Windows Forms application for recording student attendance. This project is also used to practise Git and GitHub team development.

## Features
- Enter a student name
- Select an attendance status
- Add an attendance record
- Clear attendance records
- Save records to a text file

## Technologies
- C#
- Windows Forms
- Visual Studio 2026
- Git and GitHub

## Run the Application
1. Clone the repository:
```powershell
git clone https://github.com/USERNAME/StudentAttendanceApp.git
```

2. Open `StudentAttendanceApp.slnx` in Visual Studio 2026. 
3. Build and run the application.
